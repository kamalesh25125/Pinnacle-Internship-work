Sentiment Analysis is a Natural Language Processing (NLP) technique used to determine the sentiment expressed in textual data. The objective of this project is to classify movie reviews as positive or negative using Machine Learning algorithms. A Multinomial Naive Bayes classifier was trained on the IMDb 50K Movie Reviews dataset. Text preprocessing and TF-IDF vectorization techniques were applied to convert textual reviews into numerical features suitable for machine learning. The developed model achieved an accuracy of 85.11% and was integrated into a Streamlit web application for real-time sentiment prediction.
